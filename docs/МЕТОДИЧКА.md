# Методические указания к лабораторным работам
## «Моделирование распространения компьютерных вирусов в сети»

Цикл из пяти лабораторных работ на базе «Вирусной лаборатории». Каждая работа
рассчитана на одно‑два занятия и включает теорию, порядок выполнения, таблицы для
результатов и контрольные вопросы.

**Что потребуется:** веб‑симулятор (`web/`) для наглядных опытов и/или командная
строка `virus_lab` для количественных расчётов и построения графиков.

> Напоминание: лаборатория моделирует **динамику** распространения. Она не содержит
> вредоносного кода. Все «вирусы» — это наборы параметров модели.

---

## Теоретическое введение

### Состояния узла (компартменты)

Каждый компьютер в любой момент находится в одном из состояний:

* **S** (Susceptible) — уязвим, ещё не заражён;
* **E** (Exposed) — заражён, но в инкубации, ещё не распространяет (только в SEIR);
* **I** (Infectious) — заражён и атакует другие ПК;
* **R** (Recovered) — вылечен или изолирован.

### Эпидемические модели

| Модель | Переходы | Когда применима |
|--------|----------|-----------------|
| SI | S→I | верхняя оценка, лечения нет |
| SIS | S→I→S | повторное заражение возможно (эндемичность) |
| SIR | S→I→R | иммунитет после лечения (типичная вспышка) |
| SEIR | S→E→I→R | есть инкубационный период |

### Базовое репродуктивное число R₀

**R₀** — среднее число ПК, которые заразит один заражённый за всё время болезни в
полностью уязвимой сети. Пороговая теорема:

* **R₀ < 1** — вспышка затухает;
* **R₀ > 1** — возможна эпидемия.

В однородном приближении `R₀ = β / γ`, где β — скорость заражения, γ — скорость
лечения. Порог **коллективного (сетевого) иммунитета**: чтобы остановить эпидемию,
нужно защитить долю `1 − 1/R₀` уязвимых ПК.

### Два канала распространения

* **ЛВС** — заражение идёт по связям локальной сети (рёбрам графа).
* **Торрент (P2P)** — заражённый файл раздаётся другим торрент‑пользователям и
  подкачивается из интернета; достаёт даже ПК, не подключённые к локальной сети.

## Лабораторная работа №1. Знакомство с моделью. Влияние топологии сети

**Цель:** освоить симулятор, понять связь структуры сети и скорости эпидемии.

### Порядок выполнения

1. Запустите веб‑симулятор, выберите сценарий **«01. Сетевой червь: базовый сценарий»**.
   Нажмите **Пуск**, наблюдайте расползание заражения. Обратите внимание на график
   S/E/I/R и плитки справа (пик, охват, R₀).
2. Нажмите **Сброс**. Поочерёдно меняйте **топологию** (раздел «Сеть и защита»),
   оставляя остальные параметры и seed неизменными. Для каждой топологии запишите
   результат из плиток.
3. Включите флажок **«связи сети»**, чтобы увидеть структуру графа для каждой топологии.

Либо то же самое из командной строки (усреднение по 40 прогонам):

```bash
python -m virus_lab sweep --param network.topology \
  --values corporate,flat,star,ring,grid,random,small_world,scale_free \
  --runs 40 --plot topology.png
```

## Лабораторная работа №4. Торрент‑вирусы и несвязанные компьютеры

**Цель:** изучить распространение через P2P‑сети и защиту ПК вне локальной сети.

### Порядок выполнения

1. Выберите сценарий **«08. Троян в торрент‑раздаче»**. Запустите. Обратите внимание:
   * фиолетовые ромбики — торрент‑пользователи, пунктирные кольца — ПК вне ЛВС;
   * бирюзовые (пунктирные) стрелки — заражение **через торрент**, красные — по ЛВС;
   * троян заражает даже автономные ПК (плитка «Заражено вне ЛВС»).
2. Изменяя **«Доля ПК с торрент‑клиентом»** и **«Доля ПК вне локальной сети»**
   (раздел «Торрент и несвязанные ПК»), пронаблюдайте, как меняется охват.
3. Проверьте меру защиты **«Торренты заблокированы на периметре»**. Вопрос: защищает
   ли она домашние (автономные) ПК? Сравните со сценарием из эталонов, где блокировка
   включена.
4. Сценарий **«09. Торрент‑червь»** — комбинированная угроза: вирус приходит из

## Требования к отчёту

Отчёт по каждой лабораторной работе должен содержать:

1. Цель работы и краткую теорию.
2. Описание сценария и параметров (можно приложить JSON из кнопки «Скачать сценарий»).
3. Заполненные таблицы результатов и графики (PNG из `--plot` или CSV из `--csv`).
4. Анализ результатов и ответы на контрольные вопросы.
5. Выводы: какие меры защиты и почему оказались наиболее эффективными.

## Темы для курсовых и ВКР

* Сравнение эффективности мер защиты методом Монте‑Карло с доверительными интервалами.
* Влияние безмасштабной топологии (узлы‑концентраторы) на устойчивость сети к эпидемиям.
* Оптимальная стратегия патч‑менеджмента при ограниченном бюджете (кого патчить первым).
* Моделирование гибридных угроз (торрент + ЛВС) и многоуровневой защиты.
* Калибровка параметров модели под конкретное семейство ВПО по открытым описаниям.
* Сравнение сетевой (агентной) и аналитической (SIR/SEIR) моделей: границы применимости.
